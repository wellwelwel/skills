# Security Policy

This is an open-source project, so you can see the [**Source Code on GitHub Repository**](https://github.com/wellwelwel/skills).

---

## Reporting a Vulnerability

- Please, give detailed reports
- Include steps to reproduce the vulnerability, and if possible, a patch or workaround.
- Include the specific version of **Skills** you are using.

**Reporting:**

- [**github.com/wellwelwel/skills/security/advisories**](https://github.com/wellwelwel/skills/security/advisories)

> Once the issue has been resolved, you will be attributed a part of the report.
